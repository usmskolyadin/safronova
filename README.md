# Сайт-портфолио учителя

Сайт на Django с тремя разделами: **Главная**, **Обо мне**, **Портфолио**
(«Мои достижения», «Достижения учащихся», «Методическая копилка», «Фотогалерея»).
Все тексты, фотографии и файлы редактируются через административную панель —
без правки кода.

## Быстрый запуск

```bash
# 1. Активировать виртуальное окружение
venv\Scripts\activate          # Windows (cmd/PowerShell)
source venv/Scripts/activate   # Git Bash

# 2. Установить зависимости (если ещё не установлены)
pip install -r requirements.txt

# 3. Применить миграции базы данных
python manage.py migrate

# 4. Запустить сервер разработки
python manage.py runserver
```

Сайт откроется по адресу http://127.0.0.1:8000/
Админ-панель — http://127.0.0.1:8000/admin/

## Вход в административную панель

- Логин: `admin`
- Пароль: `RusLit2025!`

**Сразу после первого входа рекомендуется сменить пароль**:
в админ-панели справа вверху — «Изменить пароль».

## Что можно редактировать в админке

| Раздел админки | За что отвечает |
|---|---|
| **Настройки сайта** | Название сайта, ФИО, должность, тексты и фото на главной, контакты, подвал сайта |
| **Страница «Обо мне»** | Фото, вступление, образование, опыт, педагогическое кредо, увлечения |
| **Страница «Портфолио»** | Заголовок и вводный текст раздела «Портфолио» |
| **Мои достижения** | Грамоты, дипломы, сертификаты (фото + описание) |
| **Достижения учащихся** | Награды учеников (фото + описание + имя ученика) |
| **Методическая копилка** | Разработки уроков, мероприятий, презентации — с прикреплённым файлом |
| **Фотогалерея** | Фотографии с уроков и мероприятий |

«Настройки сайта», «Обо мне» и «Портфолио» существуют в единственном
экземпляре — при заходе в раздел админка сразу открывает форму
редактирования.

Поле **«Порядок отображения»** во всех списках позволяет вручную
задать очерёдность карточек на сайте (меньше число — выше в списке).

## Развёртывание в интернете

Пошаговая инструкция по бесплатной публикации сайта — в [DEPLOY.md](DEPLOY.md)
(хостинг PythonAnywhere: бесплатный домен, постоянное хранилище для базы
данных и файлов, загруженных через админку).

Настройки `SECRET_KEY`, `DEBUG` и `ALLOWED_HOSTS` уже вынесены в переменные
окружения (`config/settings.py`) — локально используются безопасные
значения по умолчанию, а для продакшена они задаются в WSGI-файле хостинга
(см. DEPLOY.md).
